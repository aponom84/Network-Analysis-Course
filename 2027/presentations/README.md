## Формат: LaTeX Beamer

Все презентации курса пишутся в **Beamer** и собираются **LuaLaTeX** (XeLaTeX тоже подходит). Почему Beamer:

* **формулы** — родной LaTeX, без конвертеров; в курсе их много (MCF, MILP, спектральная теория);
* **git** — исходник текстовый, диффы читаемы, рисунки TikZ/pgfplots тоже текст;
* **у ВШЭ есть официальный Beamer-шаблон** (из брендбука, версия 2.1), на нём основана тема;
* **преемственность** — доклады по проекту логистических сетей уже написаны в Beamer, слайды и TikZ-рисунки переносятся без переделки.

Marp и reveal.js проще для текста, но формулы там идут через MathJax/KaTeX, вёрстка двух колонок и рисунков хуже, а PDF получается через браузер. PPTX и Keynote плохо живут в git.

## Сборка

```bash
make            # все презентации
make lecture    # только лекция о логистических сетях
make clean      # удалить вспомогательные файлы LaTeX
```

Нужен TeX Live (latexmk, lualatex, пакеты beamer, pgfplots, qrcode). Шрифт **HSE Sans** в репозиторий не входит: в его метаданных написано «exclusively for HSE». Его можно скачать из [брендбука](https://www.hse.ru/info/brandbook/#font) и положить в `theme/fonts/` или установить в систему. Если шрифта нет, тема берёт Fira Sans из TeX Live с предупреждением.

Новая презентация: скопируйте `template/` в новую папку `Название-Лекции/`, переименуйте `.tex` и добавьте его в `DECKS` в `Makefile`. Тема подключается через `TEXINPUTS=../theme//:`, поэтому папка лекции должна лежать рядом с `theme/`.

## Стиль

Основа — [брендбук НИУ ВШЭ](https://www.hse.ru/info/brandbook/) и официальные шаблоны презентаций (PPTX и Beamer). Тема: [`theme/beamerthemeHSEnet.sty`](./theme/beamerthemeHSEnet.sty).

### Цвета

Основной цвет — тёмно-синий **#102D69** (Pantone 287). Остальные цвета берутся из палитры шаблона ВШЭ. В TeX они доступны по именам:

| Имя | HEX | Роль |
|---|---|---|
| `hseBlue` | #102D69 | заголовки, структура, фон разделителей |
| `hseLightBlue` | #234A9B | ссылки, подзаголовки, второй цвет рисунков |
| `hseSky` | #11A0D7 | данные |
| `hseGreen` | #029C63 | «хорошо», примеры |
| `hseOrange` | #EB681F | акцент, потоки |
| `hseRed` | #E61F3D | `\alert`, предупреждения, ограничения |
| `hsePurple`, `hseYellow`, `hseSteel`, `hseTeal` | #7D4EBA, #FBBA00, #7DA0D3, #47A0A0 | дополнительные серии |
| `hsePale`, `hsePaleGreen`, `hsePaleRed`, `hsePaleYellow` | #CDDDF0, #D7EBB4, #F6C3C3, #FFDC91 | заливки |
| `hseGray`, `hseLightGray`, `hseBg` | #6B7280, #D9D9D9, #F2F5FA | подписи, сетка, фон блоков |

На одном рисунке — не больше 3–4 цветов. Цвет означает роль, и эта роль одинакова на всех слайдах лекции. Matplotlib-графики перекрашиваются в те же HEX (пример: [`Optimal-Logistics-Network/make_figs.py`](./Optimal-Logistics-Network/make_figs.py)).

### Шрифты

* **HSE Sans** — весь текст. Regular — основной текст, SemiBold — заголовки слайдов и полужирный, Bold — название лекции.
* **HSE Sans Thin** и **HSE Sans Black** брендбук рекомендует только для крупного кегля. Thin используется для номера раздела, Black — для «Вопросы?» на последнем слайде.
* Формулы — Computer Modern (`professionalfonts`), код — Fira Mono.

### Логотип

* На титульном слайде — логотип с названием «Высшая школа экономики» в левом верхнем углу.
* На обычных слайдах — круглый логотип 7 мм в левом верхнем углу (как в шаблоне ВШЭ).
* На синем фоне — версии логотипа «для тёмного фона».
* Логотип не растягивается, не перекрашивается и не обрезается: используются только файлы из брендбука в `theme/hse/`. В англоязычных материалах университет называется «HSE University», а не «NRU HSE».

### Сетка (16:9, 160 × 90 мм)

* Поля 10 мм слева и справа.
* Шапка: логотип на 4,5 мм от верха, заголовок слайда — правее логотипа на 3 мм, номер слайда — у правого поля.
* Подвал: серым 5 pt «курс · короткое название лекции».
* Титульный и разделительные слайды: полоса фирменного паттерна у правого края шириной 7,1 % слайда, как в PPTX-шаблоне ВШЭ.

### Типовые слайды

| Слайд | Как сделать |
|---|---|
| Титульный | `\maketitle`; поля `\title`, `\subtitle`, `\author`, `\institute`, `\date`, `\course`, `\lecturelabel` |
| Раздел | `\section{...}` — синий слайд с номером раздела ставится автоматически (`\usetheme[sectionpages=false]{HSEnet}` отключает) |
| Часть | `\part{...}` — синий слайд «Часть I» с названием, для лекций на несколько пар; нумерация разделов сквозная |
| Текст и список | заголовок-утверждение, 3–6 пунктов |
| Две колонки | `columns`: рисунок слева, пояснение справа |
| Определение или формула | `block`; предупреждение — `alertblock`, пример — `exampleblock` |
| Вывод | `\takeaway{...}` — плашка внизу слайда |
| Источник | `\source{...}` — мелкая серая подпись под рисунком |
| Финальный | `\finalframe{Вопросы?}{контакты, QR-коды}` |

### Правила текста

* Заголовок слайда — утверждение или вопрос, а не тема из одного слова.
* Акцент ставится `\alert` или полужирным. Подчёркивание и курсив для акцента не используются.
* Числа пишутся с десятичной запятой (`0{,}5`) и неразрывными пробелами в тысячах (`209\,257`).

## Материалы и лицензии

* `theme/fonts/` — сюда кладётся шрифт HSE Sans из брендбука ВШЭ (в репозиторий не входит).
* `theme/hse/` — логотипы ВШЭ из брендбука (`hse-seal*.pdf`, `hse-name*.pdf`) и полоса паттерна из официального PPTX-шаблона (`hse-pattern-*.png`). Это фирменные материалы ВШЭ: их можно использовать в материалах университета, но не в посторонних проектах.
* Рисунки лекции о логистических сетях построены кодом проекта [Optimal-Logistic-Net](https://github.com/aponom84/Optimal-Logistic-Net) (В. Ковалева, А. Пономаренко; код — MIT, данные — CC BY 4.0). Как перестроить:

  ```bash
  python Optimal-Logistics-Network/make_figs.py /path/to/Optimal-Logistic-Net
  ```

  Нужны только `numpy` и `matplotlib`. Скрипт берёт `make_figs.py` и `trace_figs.py` из `presentations/impulse2026/` репозитория проекта, перекрашивает их в палитру ВШЭ и пишет PDF и `figs/demo_numbers.tex` (числа примеров на Бельгии) в `Optimal-Logistics-Network/figs/`.
